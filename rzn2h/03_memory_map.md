# アドレス空間・メモリマップ

出典: ユーザーズマニュアル「5. アドレス空間」p.217-220、「4.4」p.188、各章レジスタマップ。

## アドレス空間の基本

- **Cortex-A55 / PCIE / CoreSight**: 32 GB（`0x0_0000_0000`〜`0x7_FFFF_FFFF`、35 bit）
- **Cortex-R52 およびその他マスタ**: 4 GB（`0x0000_0000`〜`0xFFFF_FFFF`、32 bit）
- 4 GB 超の領域（PCIE、DDR）へは 32 bit マスタは**ミラー領域**経由でアクセス。
  ミラーはバスマスタごとに PCIE 用 256 MB / DDR 用 512 MB を任意設定（詳細は 13.4.5 アドレス拡張）。
- 64 bit マスタは 4 GB アドレス空間経由で直接アクセス可（CoreSight ETR を除きミラー経由も可）。
- 予約領域にはアクセス禁止。予約でない領域も全アドレスが常時アクセス可能とは限らない（各章レジスタマップ参照）。

## 外部ホストインタフェース（SHOSTIF）から見たマップ（図 5.3）

- SHOSTIF（SPI 32bit/8bit モード）からは `0x00_0000` = システム SRAM (2 MB)、`0x08_0000`（8bit時 `0x20_0000`）= MBXSEM、次に SHOSTIF レジスタ、と続く簡略マップ。
