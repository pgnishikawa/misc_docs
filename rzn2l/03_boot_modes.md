# 動作モード / ブートモード

[← README（目次）へ戻る](README.md)

出典: ユーザーズマニュアル「3. 動作モード」p.89-114、「4. アドレス空間」p.115-118。

## 前提

- 本 LSI は**外付けフラッシュメモリからの起動が前提**。**8 種のブートモード**を `MD2:0` で選択。
- セキュリティ対応品は**セキュアブート**（暗号化でユーザープログラムを保護）も選択可。
- ブートは常に **Cortex-R52（唯一の CPU）** が実行 → 外部メモリからローダプログラムを
  内蔵密結合メモリ (TCM) に展開 → その先頭へ分岐。
  - RZ/N2H のような「セカンドブート CPU の選択（R52/A55）」という概念は無い（CPU が1個のため）。

## モード設定端子

### MD2 MD1 MD0（動作モード選択、リセット解除時ラッチ）

| MD2 | MD1 | MD0 | モード | ブートペリフェラル / 使用端子 |
|-----|-----|-----|--------|------------------------------|
| L | L | L | **xSPI0 ブートモード（x1 ブートシリアルフラッシュ）** | xSPI0 CS0: `XSPI0_CKP`, `XSPI0_CS0#`, `XSPI0_IO0/1` |
| L | L | H | **xSPI0 ブートモード（x8 ブートシリアルフラッシュ）**（注: 121FBGA非対応） | xSPI0 CS0: `XSPI0_CKP/CKN`, `CS0#`, `IO0-7`, `DS`, `RESET0#` |
| L | H | L | 16 ビットバスブートモード（NORフラッシュ）（注: 121FBGA非対応） | BSC: `A20-A1`, `D15-D0`, `CS0#`, `RD#` |
| L | H | H | シリアルホストインタフェースブートモード | SHOSTIF: `HSPI_CK`, `HSPI_CS#`, `HSPI_IO[n:0]`, `MBX_HINT#` |
| H | L | L | パラレルホストインタフェースブートモード（注: 121FBGA非対応） | PHOSTIF: `HCKIO`, `HA[20:m]`, `HD[n:0]`, `HCS#`, `HRD#`, `HWRSTB#`, `HWAIT#`, `HBS#`, `HWR[l:0]`, `MBX_HINT#` |
| H | L | H | SCI (UART) ブートモード（フラッシュライタ用） | SCI0: `TXD0`, `RXD0` |
| H | H | L | USB ブートモード（フラッシュライタ用、注: 121FBGA非対応） | USBf: `USB_DP`, `USB_DM` |
| H | H | H | **xSPI1 ブートモード（x1 ブートシリアルフラッシュ）**（注: 121FBGA非対応） | xSPI1 CS0: `XSPI1_CKP`, `CS0#`, `IO0/1` |

xSPI0/xSPI1/16bitバス/SHOSTIFブートは 3.3V または 1.8V をサポート（`MDV` 端子で選択）。
SCI/USBブートは電圧選択端子と無関係。

### 電圧設定端子（MDVn、I/O ドメイン 0〜4）

| MDVn | I/O ドメイン | 電圧 |
|------|------|------|
| Low | 対象ドメイン | 1.8 V |
| High | 対象ドメイン | 3.3 V |

| ドメイン | 端子 | 対象 |
|---|---|---|
| MDV0 | ETH0 | ETH0 系 I/O |
| MDV1 | ETH1 | ETH1 系 I/O |
| MDV2 | ETH2 | ETH2 系 I/O |
| **MDV3** | **XSPI0** | **xSPI0 系 I/O** |
| **MDV4** | **XSPI1** | **xSPI1 系 I/O**（121FBGAでは入力ピン自体が存在せず、常に3.3V固定） |

- MDVn 端子は他の周辺機能端子と兼用（ストラップオプション）。ブートモード確定までは
  外部からのプルアップ／プルダウンでの電圧レベル修正やフローティングは禁止。
- `MDVn` の設定と実際に `VCC1833_n` に供給する電圧は必ず一致させること（不一致は誤動作・
  永続的損傷の恐れ）。

### ハッシュ JTAG 認証端子（MDD、セキュリティ品のみ有効）

| MDD | JTAGモード |
|---|---|
| Low | 通常モード（ハッシュ JTAG 認証無効） |
| High | ハッシュモードによる JTAG 認証 |

### 動作モードモニタレジスタ (MD_MON, `SYSC_NS + 0x1100`)

実際にラッチされた値は `MD_MON`（`MD0MON`/`MD1MON`/`MD2MON`/`MDV0MON`〜`MDV4MON`/`MDDMON`）
で確認可能。本レジスタは `RES#` 端子のデアサートと同時にラッチされ、再アサートまで保持される。

## ブート処理フロー（3.5.1）

1. `MD2:0` で指定される拡張シリアルペリフェラルインタフェースまたはバスコントローラ
   （xSPI、BSC）を設定
2. 外部メモリから**ローダ用パラメータ**を読み出し、`CHECK_SUM` を検証
3. ローダ用パラメータに従い、xSPI または BSC を高速化設定
4. 外部メモリから**ローダプログラム**を読み出し、TCM へ展開
5. TCM に展開されたローダプログラムの先頭番地へ分岐

- SHOSTIF/PHOSTIF ブートは手順が異なる（外部ホスト CPU からのダウンロード）。
- SCI/USB ブートは (1)〜(4) の代わりに、ホスト PC から Motorola S-record（S0/S3/S7）で
  ローダプログラムをダウンロードする。

## ローダプログラムとローダ用パラメータの配置

| 項目 | 制約 |
|------|------|
| ローダ用パラメータの格納先 | シリアルフラッシュブート: xSPI0空間(`0x6000_0000`以上) または xSPI1空間(`0x6800_0000`以上)。パラレルフラッシュブート: 外部アドレス空間CS0(`0x7000_0000`以上) |
| ローダプログラムサイズ (`LDR_SIZE_NML`) | **512バイトの倍数、最大 120 KB** |
| ローダプログラムの展開先 (`DEST_ADDR_NML`) | **BTCM 内 `0x0010_2000`〜`0x0011_FFFF`**（4バイトアライン。Thumbならbit0=1） |
| xSPI0ブート時の格納アドレス範囲 (`LDR_ADDR_NML`) | `0x6000_004C`〜`0x60FF_FE00` |
| xSPI1ブート時の格納アドレス範囲 (`LDR_ADDR_NML`) | `0x6800_004C`〜`0x68FF_FE00` |
| 16ビットバスブート時の格納アドレス範囲 | `0x7000_004C`〜`0x701F_FFFF`（A1〜A20 の範囲） |

- BTCM 全体は `0x0010_0000`〜`0x0011_FFFF`（128 KB）。展開先として使えるのは先頭 8 KB
  （`0x0010_0000`〜`0x0010_1FFF`、ブートROM予約域）を除いた**残り 120 KB がすべて使える**
  （RZ/N2H は BTCM 64KB中52KBのみ使用可だったのに対し、RZ/N2L は BTCM 128KB中120KBを
  フルに使える計算になる）。
- ATCM（`0x0000_0000`〜`0x0001_FFFF`、128 KB）はユーザーアプリケーションプログラムの
  格納用として想定されている（ローダの展開先ではない）。

## ローダ用パラメータの内容（xSPI ブートモード時、オフセット）

| オフセット | パラメータ名 | 内容 |
|-----------|-------------|------|
| `0x00` | `CACHE_FLG` | `0x0000_0001` で Cortex-R52 の I1/D1 キャッシュを有効化（高速化） |
| `0x04` | `WRAPCFG_V` | xSPI WRAPCFG レジスタの `DSSFTCS0[4:0]` に設定される値。bit13 がフラグ（0=無視/1=有効） |
| `0x08` | `COMCFG_V` | xSPI COMCFG レジスタ設定値 |
| `0x0C` | `BMCFG_V` | xSPI BMCFG レジスタの `PREEN` ビットに設定される値 |
| `0x10` | `xSPI_FLG` | `0x2236_0679` でブート後に xSPI 設定を初期値へ戻す。それ以外はブート時の高速化設定を保持 |
| `0x14` | `LDR_ADDR_NML` | 外部メモリ内ローダプログラム先頭番地 |
| `0x18` | `LDR_SIZE_NML` | ローダプログラムサイズ（512バイトの倍数、最大120KB） |
| `0x1C` | `DEST_ADDR_NML` | 展開先（BTCM `0x0010_2000`〜`0x0011_FFFF`） |
| `0x28` | `CSSCTL_V` | xSPI CSSCTL レジスタの `CS0SIZE[5:0]` に設定される値 |
| `0x2C` | `LIOCFGCS0_V` | xSPI LIOCFGCS0 レジスタ上位16bit（ビット31-16）に設定される値。bit14がフラグ |
| `0x44` | `ACCESS_SPEED` | 外部メモリアクセス速度（`SCKCR` の `FSELXSPIn[2:0]`/`DIVSELXSPIn`） |
| `0x48` | `CHECK_SUM` | オフセット`0x00`〜`0x44`の各値を上位/下位16bitに分け合算（unsigned long） |

16ビットバスブートモード時は `CS0BCR_V`（`0x04`）/`CS0WCR_V`（`0x08`）/`BSC_FLG`（`0x10`）
にBSC用のパラメータが入る（詳細はマニュアル表3.6）。

## SCI/USB ブート認証・禁止

- OTP の `SUDIS` 設定により SCI/USB ブートを永久禁止可能。
- 認証・OTP メモリマップの詳細は今後の調査タスク（RZ/N2H の [../../rzn2h/docs/04_boot_modes.md](../../rzn2h/docs/04_boot_modes.md) に類似の仕組みがある可能性が高いが、RZ/N2L 側は本ドキュメント作成時点で未調査）。

## 使用上の注意事項（3.5.13）

- **MDVn 端子設定**: `MDVn` の設定と `VCC1833_n` への供給電圧は必ず一致させること。
  不一致はデバイスの誤動作または永続的損傷の恐れ。
- **16/32ビットバスブートモード時のバス競合**: バスが NOR フラッシュと SDRAM で共有されている場合、
  `RES#`ピンリセット・システムソフトウェアリセット・エラーリセット発生時にバス競合で
  ブート動作が機能しないことがある。対策: リセットは SDRAM がデータ出力なしの状態
  （パワーダウンモード等）に変化した後にアサートする、またはリセット時に SDRAM 電源を
  オン/オフする回路を実装する。
- **xSPI x1ブートのシリアルフラッシュリセット**: フラッシュ構成を 1S-1S-1S 以外に変更後に
  リセットが入るとブート不能になることがある → フラッシュへの外部ハードウェアリセットが必要。

## アドレス空間（ユニファイドメモリマップ、要点）

| アドレス | 領域 | サイズ |
|---|---|---|
| `0x0000_0000` | ATCM（CPU0直結） | 128 KB |
| `0x0010_0000` | BTCM（CPU0直結） | 128 KB |
| `0x1000_0000` | システムRAM | 1.5 MB |
| `0x1100_0000` | ブートROM用領域 | 64 KB |
| **`0x6000_0000`** | **外部アドレス空間 xSPI0** | **128 MB** |
| **`0x6800_0000`** | **外部アドレス空間 xSPI1** | **128 MB** |
| `0x7000_0000` | 外部アドレス空間CS0,2,3,5（BSC） | 256 MB |
| `0x8000_0000` | ノンセーフティ周辺モジュール | 16 MB |
| `0x8100_0000` | セーフティ周辺モジュール | 16 MB |

全体で 4 GB (`0x0000_0000`〜`0xFFFF_FFFF`) のアドレス空間。ミラー領域、バスマスタ
（Cortex-R52 CPU0/DMAC/GMAC,USB/CoreSight）ごとのアクセス可否の違い（TCMのAXIS経由
エイリアス等）、周辺モジュールの詳細ベースアドレス、外部ホストインタフェース
（SHOSTIF/PHOSTIF）から見えるメモリマップの**完全版は [06_memory_map.md](06_memory_map.md)
を参照**。

BSC の CS0/2/3/5 実アドレス `0x7000_0000` は `rz-fsp` の `bsp_feature.h`
（`BSP_FEATURE_BSC_NOR_CS0_BASE_ADDRESS = 0x70000000` 等）とも一致しており、
[ET1100/docs/03_rzn2l_bus_interface.md](../../ET1100/docs/03_rzn2l_bus_interface.md) の記述と
整合する（RZ/N2Hも`0x7000_0000`系だがCS数・サイズが異なるので混同注意、
[../../rzn2h/docs/](../../rzn2h/docs/)参照）。

xSPI0/xSPI1 のブートモード詳細（ブートROMの初期設定・ローダ配置制約）とランタイムでの
xSPI 操作（メモリマッピング／マニュアルコマンド／XiP／NORフラッシュ書き込みの可否）は
[04_xspi_boot_and_runtime.md](04_xspi_boot_and_runtime.md) を参照。
