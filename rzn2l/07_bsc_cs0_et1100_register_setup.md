# BSC CS0 に ET1100 を接続するためのレジスタ設定

[← README（目次）へ戻る](README.md)

出典: ユーザーズマニュアル「13. バスステートコントローラ」p.245-311、「16. I/O ポート」p.399-445、
「10. レジスタライトプロテクション機能」p.170-172、「8. 低消費電力機能」p.150-160。

前提となる接続方式は [ET1100/docs/03_rzn2l_bus_interface.md](../../ET1100/docs/03_rzn2l_bus_interface.md)
の**方式A**（`ADR[0]`/`BHE` を GND 固定し常時16bitアクセス化、`WE0#`/`WE1#` を AND ゲートで
結合して ET1100 の `WR` に接続、`WAIT#`↔`BUSY` 接続）。この方式は RZ/N2L の BSC の
**「通常空間」（TYPE=000b、リセット後のデフォルト）** に対応する。

> **本ドキュメントで扱わない範囲**: 基板配線そのもの（どの物理ピンにET1100のどの信号を
> 繋ぐか）はハードウェア設計の裁量であり、後述のピン表はあくまで**選択肢の提示**。
> 実際に使用するピンは基板設計に応じて選び、対応する `PFC` 値に読み替えること。

## 0. 全体フロー

```
① レジスタライトプロテクション解除 (PRCRS.PRC2, PRCRN.PRC1/PRC2)
        │
② I/Oポートの領域選択 (RSELPm ＝ ノンセーフティ)
        │
③ I/Oポートのピン機能設定 (PMCm ＝ 周辺機能、PFCm ＝ BSC機能番号)
        │
④ （必要ならプロテクション再ロック）
        │
⑤ BSCモジュールストップ解除 (MSTPCRA.MSTPCRA00 = 0)
        │
⑥ CS0BCR / CS0WCR_0 設定
        │
⑦ （必要ならプロテクション再ロック）
        │
⑧ CS0空間 (0x7000_0000〜) へアクセス可能
```

**①〜③・⑤〜⑥の順序は厳守**すること。特に、レジスタライトプロテクションを解除する前に
`RSELPm`/`PMCm`/`PFCm`/`MSTPCRA` へ書き込んでも**無視される**（プロテクトビットが0の間は
書き込み禁止）。

## 1. レジスタライトプロテクションの解除

出典: マニュアル第10章。`PMC/PFC/DRCTL/RSELP` と `MSTPCRA` はいずれも書き込み保護されて
いるため、対応するプロテクトレジスタを先に解除する必要がある。

| レジスタ | ベースアドレス | 保護対象 | 備考 |
|---|---|---|---|
| **PRCRS**（セーフティ領域プロテクト） | `0x8128_1A00` | `RSELP00`〜`RSELP24`（PRC2）ほか | `RSELPm` 自体はセーフティ領域のレジスタとして保護される |
| **PRCRN**（ノンセーフティ領域プロテクト） | `0x8028_1A10` | `PMC00`〜`PMC24`／`PFC00`〜`PFC24`／`DRCTL00`〜`DRCTL24`（PRC2）、`MSTPCRA`〜`E`（PRC1） | |

書き込み時は **`PRKEY[7:0]` に必ず `0xA5` を同時に書く**（それ以外の値は無視される）。

```c
#define PRCRS   (*(volatile uint32_t *)0x81281A00u)
#define PRCRN   (*(volatile uint32_t *)0x80281A10u)

/* PRCRS: PRC2(RSELP関連)を解除 */
PRCRS = 0x0000A504u;   /* PRKEY=0xA5, PRC2=1 */

/* PRCRN: PRC1(MSTPCRA関連) と PRC2(PMC/PFC/DRCTL関連) を同時に解除 */
PRCRN = 0x0000A506u;   /* PRKEY=0xA5, PRC2=1, PRC1=1 */
```

設定完了後は、同じレジスタに `PRKEY=0xA5` かつ対象ビット=0 を書いて**再ロック**するのが
安全（本ドキュメント末尾のサンプルコードで実施）。

## 2. I/Oポートの領域選択（RSELPm）★見落としやすい

**`RSELPm` はリセット後デフォルトで「セーフティ領域」を選択しており、
ノンセーフティアドレス（`0x800A_0xxx`、通常のアプリケーションが使うアドレス）からの
`PMCm`/`PFCm`/`DRCTLm` への書き込みは、対応するビットが1になるまで読み出し専用のまま**
（マニュアル16.3.7）。これを見落とすと、`PMCm`/`PFCm` に書き込んだつもりでも実際には
反映されず、ピンが GPIO のまま変化しない、という分かりにくい不具合になる。

| レジスタ | ベースアドレス | オフセット |
|---|---|---|
| RSELPm | `0x8103_0C00`（固定、PTADR） | `0x000 + 0x001 × m` |

ビット `n`（対応するポート `Pm_n`）を `1` にすると、そのピンの `PMCm`/`PFCm`/`DRCTLm` は
**ノンセーフティアドレス（`0x800A_0xxx`）から R/W 可能**になる（`0` のままだとセーフティ
アドレス `0x8103_0xxx` からのみ R/W 可能）。**通常のノンセーフティアプリケーションで
BSC を使う場合、使用する全ピンについて対応するビットを1にする。**

## 3. I/Oポートのピン機能設定（PMCm／PFCm）

| レジスタ | ベースアドレス（ノンセーフティ） | オフセット | 内容 |
|---|---|---|---|
| PMCm | `0x800A_0000` | `0x400 + 0x001 × m` | ビットn=1でピンPm_nを周辺機能（BSC等）に切替。0=GPIO |
| PFCm | `0x800A_0000` | `0x600 + 0x004 × m` | 4bit×8ピン。ピンPm_nの機能番号（0〜15）を選択 |

### 3.1 方式A（16bit固定・WE0/WE1をAND合成）に必要な信号

| 信号 | 用途 | 必要本数 |
|---|---|---|
| `CS0#` | チップセレクト | 1 |
| `RD#` | 読み出しストローブ（ET1100 `RD` へ直結） | 1 |
| `WE0_DQMLL`（=`WE0#`） | 書き込みストローブ（下位バイト） | 1 |
| `WE1_DQMLU`（=`WE1#`） | 書き込みストローブ（上位バイト）。**`WE0#`とANDして ET1100 `WR` へ** | 1 |
| `WAIT` | 外部ウェイト入力。ET1100 `BUSY` へ接続 | 1 |
| `A1`〜`A16` | アドレスバス（ET1100 `ADR[15:0]` に1bitずれで接続、`ET1100/docs/03_rzn2l_bus_interface.md` §3.4参照。`A0`は未使用でよい） | 16 |
| `D0`〜`D15` | データバス | 16 |

`RD_WR`（方向信号）・`BS`（バスサイクル開始）は ET1100 側で使わないため配線・設定不要
（マニュアル13.4.2に「外部データバッファを制御しない場合は不要」の趣旨の記載あり）。

### 3.3 設定例（1組の具体的なピン割当てを選んだ場合）

以下は上表から重複なく1組選んだ**例**（実際の基板配線に合わせて読み替えること）。

| ポート m | 使用ピン（信号） | `PMCm` 値 | `PFCm` 値 |
|---|---|---|---|
| P00 | 0(D15,0x2) 1(A13,0x3) 2(RD,0x2) 4(WAIT,0x3) 5(CS0,0x2) | `0x37` | `0x0023_0232` |
| P01 | 4(WE1,0x2) 5(WE0,0x1) | `0x30` | `0x0012_0000` |
| P02 | 2(A16,0x2) 3(A15,0x2) | `0x0C` | `0x0000_2200` |
| P03 | 0(A14,0x2) 5(A12,0x2) 6(A11,0x3) 7(A10,0x3) | `0xE1` | `0x3320_0002` |
| P04 | 0(A9,0x1) 4(A8,0x2) 5(A7,0x0) 6(A6,0x1) 7(A5,0x1) | `0xF1` | `0x1102_0001` |
| P05 | 0(A4,0x2) 1(A3,0x2) 2(A2,0x2) 3(A1,0x2) | `0x0F` | `0x0000_2222` |
| P15 | 3(D11,0x3) 4(D12,0x3) 5(D13,0x2) 6(D14,0x3) | `0x78` | `0x0323_3000` |
| P21 | 1(D0,0x1) 2(D1,0x1) 3(D2,0x1) 4(D3,0x1) 5(D4,0x2) 6(D5,0x2) 7(D6,0x2) | `0xFE` | `0x2221_1110` |
| P22 | 0(D7,0x2) 1(D8,0x1) 2(D9,0x2) 3(D10,0x0) | `0x0F` | `0x0000_0212` |

**`RSELPm` は同じポートに対して、使用するピンだけ同じビットパターンで1にする**
（例: `RSELP00 = 0x37`、`RSELP01 = 0x30`、…、`RSELP22 = 0x0F`）。

計算式（任意のピン割当てに一般化）:
```
PMCm  = Σ (1 << pin_no)                    使用する各ピンについて
RSELPm = PMCm と同じビット位置に1を立てる    （＝使用ピンのみノンセーフティに切替）
PFCm  = Σ (function_code << (4 × pin_no))  使用する各ピンについて
```

## 4. BSCモジュールストップの解除（MSTPCRA）

| レジスタ | ベースアドレス | オフセット | ビット |
|---|---|---|---|
| MSTPCRA | `0x8028_0000`（SYSC_NS） | `0x0300` | bit0 = BSC（0=動作、1=停止＝リセット後デフォルト） |

```c
#define MSTPCRA (*(volatile uint32_t *)0x80280300)
MSTPCRA &= ~0x00000001u;   /* bit0=0: BSC のモジュールストップを解除 */
```

（`MSTPCRA` は §1 の `PRCRN.PRC1` 解除が済んでいないと書き込めない。）

## 5. BSC本体レジスタ（CS0BCR／CS0WCR_0）

これらのレジスタは**ライトプロテクションの対象外**（PRCRの保護範囲は
`0x800A_0000`/`0x8028_0000`/`0x8103_0000`/`0x8128_0000` 系のみで、BSC本体
`0x8021_0000` 系は含まれない）なので、そのまま書き込める。

### 5.1 CS0BCR : CS0空間バスコントロールレジスタ

| ベースアドレス | オフセット | アドレス |
|---|---|---|
| `0x8021_0000` | `0x004`（n=0） | `0x8021_0004` |

| ビット | シンボル | 設定値 | 意味 |
|---|---|---|---|
| 14:12 | `TYPE[2:0]` | `000b`（**リセット後デフォルト、変更不要**） | 通常空間（Normal space） |
| 10:9 | `BSZ[1:0]` | `10b`（**リセット後デフォルト、変更不要**） | 16bit固定 |
| 30:16 | `IWW`/`IWRWD`/`IWRWS`/`IWRRD`/`IWRRS` | 各 `011b`（**リセット後デフォルト**） | アイドルサイクル4（性能要件が厳しくなければ変更不要） |

**結論: CS0BCR はリセット値 `0x36DB_0C00` のままで方式Aの要件を満たす。**
明示的に書き込む場合も同じ値でよい（他コードが誤って変更していないことの保証、
可読性のために明示書き込みを推奨）。

```c
#define CS0BCR (*(volatile uint32_t *)0x80210004)
CS0BCR = 0x36DB0C00u;   /* TYPE=通常空間, BSZ=16bit（リセット値と同一） */
```

### 5.2 CS0WCR_0 : CS0空間ウェイトコントロールレジスタ（通常空間／バイト選択付きSRAM向け）

| ベースアドレス | オフセット | アドレス |
|---|---|---|
| `0x8021_0000` | `0x028` | `0x8021_0028` |

| ビット | シンボル | 設定値 | 意味 |
|---|---|---|---|
| 20 | `BAS` | `0`（**リセット後デフォルト**） | `WEn#`＝書き込み時のみ有効（方式Aの前提と一致） |
| 6 | `WM` | `0`（**リセット後デフォルト**） | **外部 `WAIT#` 入力を有効化**（ET1100 `BUSY` との連携に必須） |
| 10:7 | `WR[3:0]` | `0xA`＝14サイクル（**リセット後デフォルト**。性能要件次第で減らしてよい） | ソフトウェアウェイト（`WAIT#`による延長の「土台」。正しさ自体は`WAIT#`が保証するため、この値は安全側に倒しておけば十分） |
| 12:11 | `SW[1:0]` | `00b`（0.5サイクル、**デフォルト**） | CS0#/アドレスアサートからRD#/WEn#アサートまでの遅延 |
| 1:0 | `HW[1:0]` | `00b`（0.5サイクル、**デフォルト**） | RD#/WEn#ネゲートからCS0#/アドレスネゲートまでの遅延 |

**結論: CS0WCR_0 もリセット値 `0x0000_0500` のままで方式Aの要件を満たす**
（`WM=0` により ET1100 の `BUSY`→`WAIT#` ハンドシェイクが最初から有効）。

```c
#define CS0WCR_0 (*(volatile uint32_t *)0x80210028)
CS0WCR_0 = 0x00000500u;  /* BAS=0, WM=0(外部WAIT有効), WR=14cyc, SW=HW=0.5cyc（リセット値と同一） */
```

**性能を詰めたい場合**: `WM=0` のまま `WR[3:0]` を `0x0`（ウェイトなし）まで下げても、
実際のアクセス完了は `WAIT#`（ET1100 `BUSY`）が延長するため**正しさは損なわれない**。
ただし `BUSY` の応答が非常に速いケース（[ET1100/docs/03_rzn2l_bus_interface.md](../../ET1100/docs/03_rzn2l_bus_interface.md)
§3.5の `tCS_to_BUSY` 最大15ns 等）で BSC 側の外部ウェイトサンプリングタイミングと
競合しないか、実機波形で確認すること。

## 6. 任意（必要に応じて検討する）レジスタ

| レジスタ | 用途 | 本設計での要否 |
|---|---|---|
| `DRCTLm`（I/Oバッファ機能切替、ベース`0x800A_0000`/`0x8103_0000`、オフセット`0xA00+8×m`） | プルアップ/プルダウン・駆動能力・シュミットトリガ・スルーレート | **通常は不要**（リセット値で動作可能）。ノイズ対策として`WAIT`入力にシュミットトリガ（`SMTn=1`）を検討する余地はある |
| `SCKCR`（クロック発生、`PRCRN.PRC0`で保護） | 外部バスクロック（`CKIO`）／BSCの内部動作クロック元の分周設定 | **確認のみ推奨**。リセット後のデフォルトで動作クロックが供給されている前提だが、他の初期化コードが `SCKCR` を変更している場合は BSC の実効速度に影響するため、システムクロック設定と合わせて確認すること（本ドキュメントでは値を確定できない：ボードのクロック構成に依存） |
| `TOSCOR0`／`TOSTR`／`TOENR`（タイムアウト機能） | `WAIT#`（`BUSY`）がハードウェア異常で永久に解除されない場合の安全装置（タイムアウト検出） | **オプション**。ET1100故障時のフェイルセーフとして有効化を検討してよいが、正常動作には不要 |
| `ICU` 関連レジスタ | ET1100 `IRQ` ピンを外部割り込みとして使う場合 | **BSCとは無関係**。[04_xspi_boot_and_runtime.md](04_xspi_boot_and_runtime.md)ではなく[ET1100/docs/04_software_bringup.md](../../ET1100/docs/04_software_bringup.md) §4.5 の `r_icu` 設定を参照 |

## 8. サンプル初期化コード（§3.3のピン割当て例に基づく）

```c
#include <stdint.h>

/* ---- レジスタ定義 ---- */
#define PRCRS     (*(volatile uint32_t *)0x81281A00u)
#define PRCRN     (*(volatile uint32_t *)0x80281A10u)
#define MSTPCRA   (*(volatile uint32_t *)0x80280300u)
#define CS0BCR    (*(volatile uint32_t *)0x80210004u)
#define CS0WCR_0  (*(volatile uint32_t *)0x80210028u)

#define PORT_NS_BASE 0x800A0000u
#define PORT_RSELP_BASE 0x81030C00u
#define RSELPm(m)  (*(volatile uint8_t  *)(PORT_RSELP_BASE + (m)))
#define PMCm(m)    (*(volatile uint8_t  *)(PORT_NS_BASE + 0x400u + (m)))
#define PFCm(m)    (*(volatile uint32_t *)(PORT_NS_BASE + 0x600u + 4u * (m)))

/* ポート番号 (m) は「Pxx」の xx をそのまま使う（P00→m=0, P05→m=5, P15→m=15, P22→m=22 等）。
 * ※ m=11（P11）は欠番。P00〜P10 は m=0〜10、P12以降は m=12〜24 とマニュアルに明記されている。 */
#define M_P00  0
#define M_P01  1
#define M_P02  2
#define M_P03  3
#define M_P04  4
#define M_P05  5
#define M_P15  15
#define M_P21  21
#define M_P22  22

void bsc_cs0_et1100_pin_init(void)
{
    /* 1. ライトプロテクション解除 (RSELP用のPRC2, PMC/PFC/MSTPCRA用のPRC1+PRC2) */
    PRCRS = 0x0000A504u;
    PRCRN = 0x0000A506u;

    /* 2. RSELPm: 使用ピンをノンセーフティ領域へ */
    RSELPm(M_P00) = 0x37u;
    RSELPm(M_P01) = 0x30u;
    RSELPm(M_P02) = 0x0Cu;
    RSELPm(M_P03) = 0xE1u;
    RSELPm(M_P04) = 0xF1u;
    RSELPm(M_P05) = 0x0Fu;
    RSELPm(M_P15) = 0x78u;
    RSELPm(M_P21) = 0xFEu;
    RSELPm(M_P22) = 0x0Fu;

    /* 3. PMCm: 使用ピンを周辺機能(BSC)へ切替 */
    PMCm(M_P00) = 0x37u;
    PMCm(M_P01) = 0x30u;
    PMCm(M_P02) = 0x0Cu;
    PMCm(M_P03) = 0xE1u;
    PMCm(M_P04) = 0xF1u;
    PMCm(M_P05) = 0x0Fu;
    PMCm(M_P15) = 0x78u;
    PMCm(M_P21) = 0xFEu;
    PMCm(M_P22) = 0x0Fu;

    /* 4. PFCm: BSC機能番号を選択 (§3.3の割当て例) */
    PFCm(M_P00) = 0x00230232u;  /* D15,A13,RD,WAIT,CS0 */
    PFCm(M_P01) = 0x00120000u;  /* WE1,WE0 */
    PFCm(M_P02) = 0x00002200u;  /* A16,A15 */
    PFCm(M_P03) = 0x33200002u;  /* A14,A12,A11,A10 */
    PFCm(M_P04) = 0x11020001u;  /* A9,A8,A7,A6,A5 */
    PFCm(M_P05) = 0x00002222u;  /* A4,A3,A2,A1 */
    PFCm(M_P15) = 0x03233000u;  /* D11,D12,D13,D14 */
    PFCm(M_P21) = 0x22211110u;  /* D0-D6 */
    PFCm(M_P22) = 0x00000212u;  /* D7,D8,D9,D10 */

    /* 5. プロテクション再ロック (RSELP/PMC/PFC分, PRC2=0) */
    PRCRS = 0x0000A500u;

    /* 6. BSC モジュールストップ解除 (PRCRN.PRC1 はまだ解除済み) */
    MSTPCRA &= ~0x00000001u;

    /* 7. プロテクション再ロック (MSTPCRA/PMC/PFC分, PRC1=PRC2=0) */
    PRCRN = 0x0000A500u;

    /* 8. BSC CS0 レジスタ設定 (通常空間・16bit・外部WAIT有効 = リセット値と同一だが明示) */
    CS0BCR   = 0x36DB0C00u;
    CS0WCR_0 = 0x00000500u;

    /* これで 0x7000_0000 (CS0 実領域) への 16bit アクセスが有効になる。
     * 以降は ET1100/docs/03_rzn2l_bus_interface.md §3.6 の
     * et1100_reg_read16()/et1100_reg_write16() 等で ET1100 と通信できる。 */
}
```

## 9. チェックリスト

- [ ] `PRCRS`/`PRCRN` を正しい `PRKEY=0xA5` で解除してから `RSELPm`/`PMCm`/`PFCm`/`MSTPCRA`
      を書いている（順序を間違えると無視される）
- [ ] 使用する全ピンについて `RSELPm` のビットを立てている（デフォルトはセーフティ領域＝
      ノンセーフティからは読み出し専用）
- [ ] `PMCm`（周辺機能へ切替）と `PFCm`（機能番号選択）の両方を設定している
- [ ] `MSTPCRA.MSTPCRA00 = 0` で BSC のモジュールストップを解除している
- [ ] `CS0WCR_0.WM = 0`（外部ウェイト有効）を確認し、`WAIT#`⇔`BUSY` の配線と対応させている
- [ ] `CS0BCR.TYPE = 000b`（通常空間）・`BSZ = 10b`（16bit）を確認している
- [ ] `A0`をET1100へ接続せず、`RZN2L A(n+1)`→`ET1100 ADR(n)`の1bitオフセット配線になっている
      （[ET1100/docs/03_rzn2l_bus_interface.md](../../ET1100/docs/03_rzn2l_bus_interface.md) §3.4）
- [ ] `WE0#`/`WE1#` を AND ゲートで結合して ET1100 `WR` に接続している
- [ ] ソフトウェアが `volatile uint16_t*` 以外でこの CS0 空間にアクセスしていない
- [ ] （マルチコア/DMA非該当だが念のため）ET1100用アドレス範囲を MPU で Device属性に設定
      している（[ET1100/docs/03_rzn2l_bus_interface.md](../../ET1100/docs/03_rzn2l_bus_interface.md) §3.9）
