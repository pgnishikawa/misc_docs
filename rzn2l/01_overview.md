# RZ/N2L 概要

[← README（目次）へ戻る](README.md)

出典: ユーザーズマニュアル ハードウェア編 R01UH0955JJ0130 Rev.1.30（2023-12-08）、
「1. 概要」p.54〜84。

## 位置づけ

- FPU / NEON を備える **Arm Cortex-R52 シングルコア**の産業ネットワーク向け ASSP。
- RZ/N シリーズ（産業ネットワーク用）。モータ制御、産業用イーサネット、EtherCAT 等の
  用途を想定した周辺機能を統合。
- RZ/N2H（[../../rzn2h/docs/](../../rzn2h/docs/) に別途調査あり）と同じ RZ/N シリーズだが、
  **RZ/N2H が Cortex-A55 クワッド＋Cortex-R52 デュアルのハイエンド機**なのに対し、
  **RZ/N2L は Cortex-R52 シングルコアのローエンド機**という位置づけ。マニュアルも別冊
  （RZ/N2L 専用、RZ/T2H との共用マニュアルではない）。

## CPU

| 項目 | 内容 |
|------|------|
| コア | Arm Cortex-R52（**シングルプロセッサ**、Core revision **r1p2**） |
| 動作周波数 | 200/400 MHz（システムクロック 200 MHz 時）または 150/300 MHz（システムクロック 150 MHz 時） |
| アーキテクチャ | Arm v8-R、Thumb/Thumb-2 サポート |
| アドレス空間 | 4 GB (32bit) |
| L1 キャッシュ | 命令 16 KB（ECC）／データ 16 KB（ECC） |
| TCM | ATCM 128 KB（ECC、0 ウェイト）／BTCM 128 KB（ECC、0 ウェイト）／CTCM 0 KB |
| MPU | 2 ステージ（EL2/EL1）、各 24 領域 |
| エンディアン | 命令・データともリトルエンディアン |
| FPU/NEON | 単精度・倍精度の四則演算・積和・平方根、Advanced SIMD（整数・単精度） |

- RZ/N2H の Cortex-R52 は ATCM 512 KB / BTCM 64 KB だったのに対し、**RZ/N2L は ATCM 128 KB / BTCM 128 KB**（配分が異なる）。
- DCLS（デュアルコアロックステップ）や2つ目のCPUは無い（RZ/N2H は R52 を2個搭載）。

## メモリ

| メモリ | 仕様 |
|--------|------|
| 内蔵システム SRAM | 最大 **1.5 MB**（512 KB × 3 ユニット）、ECC (SEC-DED)、150/200 MHz、エラーインジェクション対応 |
| ブート ROM | 64 KB（`0x1100_0000`〜、[03_boot_modes.md](03_boot_modes.md)） |
| OTP | 上書き保護・冗長機能。ユニーク ID／認証設定／トリミングデータ／ブートモード設定／ユーザー領域 |
| 外部アドレス空間（BSC） | 4 CS 領域（CS0/CS2/CS3/CS5）、8/16 bit、外部バスクロック最高 100 MHz |
| xSPI | 2 チャネル。詳細は [04_xspi_boot_and_runtime.md](04_xspi_boot_and_runtime.md) |

RZ/N2H（システム SRAM 2.0 MB、外部バス 32bit まで、xSPI RAW 266 MB/s）と比べると、
RZ/N2L はシステム SRAM 1.5 MB、外部バス幅は 8/16 bit まで（32bit 非対応）、xSPI RAW
200 MB/s と、いずれもややスケールダウンした仕様になっている。

## 動作モード（ブート）（詳細: [03_boot_modes.md](03_boot_modes.md)）

- **8 種類のブートモード**を `MD2:0` ピンで選択（RZ/N2H は 7 種類）。
  - xSPI0 ブート（x1 / x8 ブートシリアルフラッシュ）
  - 16 ビットバスブートモード（CS0 NOR フラッシュ）
  - SHOSTIF ブートモード／PHOSTIF ブートモード（外部ホスト CPU からのダウンロード）
  - SCI (UART) ブートモード／USB ブートモード（フラッシュライタ用）
  - xSPI1 ブートモード（x1 ブートシリアルフラッシュ）
- ブートは常に **Cortex-R52 の単一 CPU**が実行（RZ/N2H のような「セカンドブート CPU 選択」の概念は無い。CPU が1個しかないため）。
- セキュリティ対応品はセキュアブート（暗号化によるユーザープログラム保護）も選択可。

## クロック

| クロック | 周波数 |
|---|---|
| システムクロック | 150 MHz または 200 MHz（選択） |
| CPU0 クロック | システムクロック ×1 または ×2（つまり 150/300 MHz または 200/400 MHz） |
| 高速周辺モジュールクロック | 150 MHz または 200 MHz |
| 中速周辺モジュールクロック | 75 MHz または 100 MHz |
| 低速周辺モジュールクロック | 37.5 MHz または 50 MHz |
| ADC クロック | 25 MHz または 18.75 MHz |
| 外部バスクロック | 最高 100 MHz |
| 低速オンチップオシレータ (LOCO) | 240 kHz（固定） |

入力クロックは外部クロックまたは外部発振子から選択、発振停止検出あり。

## 割り込みコントローラ (ICU)

- 周辺機能割り込み: **423 要因**
- 外部割り込み: **16 要因**（IRQ0〜IRQ15 端子）
- ソフトウェア割り込み: **8 要因**
- ノンマスカブル割り込み: 1 要因
- **32 レベル**の割り込み優先順位を設定可能

（RZ/N2H は周辺機能割り込み 394、ソフトウェア割り込み 16、GIC-600/GIC 経由。RZ/N2L は
GIC0 のみで単純。メモリマップ上 `0x9400_0000` に GIC0 が 2 MB でマップ、[03_boot_modes.md](03_boot_modes.md) のメモリマップ参照。）

## バスステートコントローラ (BSC)

- 外部アドレス空間を **4 領域（CS0、CS2、CS3、CS5）**に分割して管理。
- 領域ごとに独立設定可能: バスサイズ（8/16 bit、**32bit 非対応**）、アクセスウェイトサイクル数
  （読み出し／書き込みで別設定可）、アイドルウェイト挿入、CS のアサート／ネゲートタイミング。
- 各領域に接続可能なメモリタイプ:
  - CS0: SRAM、バースト ROM
  - CS2: SRAM
  - CS2+CS3: SRAM、SDRAM（CS2 単独での SDRAM は非サポート）
  - CS3: SRAM、SDRAM
  - CS5: SRAM、MPX-IO（アドレス／データマルチプレクス）
- SDRAM はオートリフレッシュ／セルフリフレッシュモード選択可、バーストアクセス対応。
- 外部アドレス空間（CS0/2/3/5 合計）は `0x7000_0000`〜256 MB、ミラー領域が `0x5000_0000`〜
  （[03_boot_modes.md](03_boot_modes.md) のユニファイドメモリマップ参照）。

> `ET1100/docs/` の RZ/N2L 外部バス接続資料（[../../ET1100/docs/03_rzn2l_bus_interface.md](../../ET1100/docs/03_rzn2l_bus_interface.md)）とは、この BSC の CS0/2/3/5・SRAM(Normal space)・8/16bit幅・外部ウェイトという仕様面で一致する。BSC 自体のレジスタ詳細（マニュアル第13章）は今後の調査タスク。

## DMA・イベント

- **DMAC**: 2 ユニット × 8 チャネル。転送モード: シングル／ブロック。転送サイズはユニット0が
  1/2/4/8/16/32/64 バイト、ユニット1が1/2/4/8/16/32 バイト。起動要因: ソフトウェアトリガ、
  外部 DMA 要求 (DREQ)、外部割り込み、周辺機能割り込み。
- **ELC（イベントリンクコントローラ）**: 最大 **217** イベント信号をモジュール動作に連動可能
  （RZ/N2H は最大632）。ポート16・18のイベントリンクにも対応。

## 主な周辺機能一覧

### タイマ
| モジュール | 数量・要点 |
|-----------|------|
| MTU3 | 9 チャネル（16bit×8 ＋ 32bit×1）。最大28本パルス入出力、最高動作周波数200 MHz |
| GPT（32 bit） | **18 チャネル** |
| CMT（16 bit） | 2ch × 3 ユニット（6ch）、最高50 MHz |
| CMTW（32 bit） | 1ch × 2 ユニット、最高50 MHz |
| WDT | 14 bit × **1 チャネル**（RZ/N2H は6ch） |
| POE3 | MTU3出力のHi-Z制御。入力5端子（POE0#/4#/8#/10#/11#） |
| POEG | GPT出力禁止制御 |
| RTC | 2000〜2099年、BCD表示、うるう年自動補正 |

### 通信
| モジュール | 数量・要点 |
|-----------|------|
| イーサネット MAC (GMAC) | 1ポート。10/100/1000BASE、IEEE1588、MII/RMII/RGMII |
| イーサネットスイッチ (ETHSW) | 3ポートPHY I/F。ハードウェアスイッチング、QoS、VLAN、DLR、PRP、TDMAスケジューラ |
| **EtherCAT スレーブコントローラ (ESC)** | **1チャネル（3ポート）。Beckhoff Automation 製 EtherCAT スレーブコントローラ IP コアをオンチップ内蔵**。外部 RGMII コンバータで MII/RMII/RGMII 対応 |
| USB2.0 HS | 1ポート。ホスト/ファンクション/OTG。HS(480M)/FS/LS。DMAC 2ch内蔵 |
| SCI | 6チャネル。調歩同期/クロック同期/簡易I2C/簡易SPI/スマートカード |
| I2C (IIC) | 3チャネル。最大400 kbps |
| CAN-FD | 2チャネル。ISO 11898-1(2015)。合計192メッセージバッファ、受信ルール最大256 |
| SPI | 4チャネル。転送ビット長8〜32bit、128bitバッファ、1回で最大4フレーム |
| **xSPI** | **2チャネル**。JESD251準拠、1/4/8pin SDR/DDR、OctaFlash/RAM・HyperFlash/RAM対応、XiPモード対応、CSあたり最大64MB、RAW 200MB/s。詳細は [04_xspi_boot_and_runtime.md](04_xspi_boot_and_runtime.md) |
| SHOSTIF（外部ホストI/F） | シリアル（4線SPI/Dual/Quad/Octal拡張）。外部ホストCPUからのスレーブアクセス用 |
| PHOSTIF（外部ホストI/F） | 同期/非同期SRAM I/Fモード。バス幅8/16bit |
| MBXSEM | セマフォ8、32bitメールボックス4（外部ホストCPU⇔Cortex-R52 双方向） |

**重要な事実**: RZ/N2L は **EtherCAT スレーブコントローラ (ESC) を内蔵**しており、Beckhoff の
IP コアがオンチップで搭載されている。外付けの ET1100（[ET1100/docs/](../../ET1100/docs/)）と
機能的には同種のものである。両方が本リポジトリの調査対象に含まれているのは、内蔵 ESC と
外付け ET1100 のどちらを採用するかを比較検討している、または既存基板の都合で外付け ET1100
を使う設計になっている、といった事情によるものと推測される（詳細な採否理由は本ドキュメントの
範囲外）。

## ブロック図（p.65 のテキスト表現、225 ピン品）

- **Cortex-R52 (CPU0)** ＋ GIC ＋ MPU → 内部メインバスに接続。
- **内部メインバス**に接続: GMAC×1、ETHSW×3ポート、**ESC×3ポート**、USB×1、DMAC×2ユニット
  （各8ch）、内蔵システムSRAM（ECC付き）、xSPI×2ch、BSC、OTP、セキュリティ、SHOSTIF、
  PHOSTIF、MBXSEM。
- **モータサブシステム用周辺モジュール**（LLPPバス側）: MTU3、GPT（ユニット0：4ch）、
  POEG（ユニット0）、TFU、POE3、12bit ADC（ユニット0）、DSMIF（ユニット0/1：6ch）。
- **ノンセーフティ機能用周辺モジュール**: ELC、CMT×6ch（ユニット0〜2）、CMTW×2ch（ユニット0/1）、
  GPT×10ch（ユニット1）、POEG（ユニット1）、WDT×1ch、12bit ADC（ユニット1）、SCI×5ch、
  IIC×2ch、CANFD×2ch、SPI×3ch、CRC（ユニット0）、DOC、TSU。ポート0〜24に接続。
- **セーフティ機能用周辺モジュール**: GPT×4ch（ユニット2）、POEG（ユニット2）、RTC、
  CRC（ユニット1）、SCI×1ch、IIC×1ch、SPI×1ch、CLMA。
